KSR Food Bot 🍔

AI-Based Budget-Friendly Food Recommendation Chatbot

KSR Food Bot is a simple chatbot developed using Python and Streamlit. It helps users find vegetarian food options based on their budget and food preferences.

Features

- User Login
- Budget-Based Food Recommendations
- Vegetarian Food Preference
- College Campus Location
- Interactive Chatbot Interface

Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install -r requirements.txt"
3. Run the application:
   "streamlit run app.py"
